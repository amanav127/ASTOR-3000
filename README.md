# ASTOR-3000
A room arrangement where evrything can be 3d printed and kept in that way to get a working, spacious, multi-functional room...
To see the model, go to this link => https://cad.onshape.com/documents/1f9e5b8d4ef4a789216cfe3e/w/84466cca263f68d04777ab5e/e/1b0f67fa338e9111dadab1f6?renderMode=0&uiState=6a82fc1b2e83706789f13a80
The room should be at least 3m x 4m with minimum height of 2m
The parts are better 3d printed, which might sound highly impractical, but it does have its bright sides (the cleaning will be easy, less time wasted for that...)
So, there is a table which has a specialised area for Paperwork and writing, and an in-built pen holder.
A computer table attached so that you can do paperwork alongside it.
An electronics table where you can do hardware work.
